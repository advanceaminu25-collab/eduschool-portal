# EduCore School Management Portal

EduCore is a responsive school management portal demonstration
built with HTML, CSS, and JavaScript.

## Features

- Dashboard overview
- Student registration, search, editing, and deletion
- Teacher and staff directory
- Class and subject overview
- Attendance register
- Examination results and indicative grades
- Fee record tracking
- School announcements
- School profile and academic settings
- Example subscription plans
- JSON data export
- Responsive desktop and mobile layout

## How to Run

1. Download or clone the repository.
2. Open index.html in a modern browser.
3. Use the sidebar to navigate between modules.
4. Add test records and try the available features.

## Project Structure

educore-school-portal/

## GitHub Pages

1. Create a GitHub repository.
2. Upload index.html, the css folder, the js folder, and README.md.
3. Open the repository's Settings.
4. Select Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and the root folder (/).
7. Save and wait for deployment.
8. Open the published URL provided by GitHub.

## Data Storage

This version uses localStorage in the current browser.

Records are not shared between different users or devices.
Clearing browser storage can remove records.

## Production Requirements

Before using this system for real schools, implement:
- Secure server-side authentication
- School-specific accounts and permissions
- A shared database and API
- Server-side input validation
- Backups and audit logs
- Secure document storage
- Payment gateway integration
- Privacy and data protection controls

GitHub Pages hosts static files only. It does not provide the
backend required for a secure, multi-school subscription service.

## Subscription Notice

Displayed prices are examples. Selecting a plan does not activate
a subscription or collect payment.
